# Social Proof(사회적 증거)의 중요성

> **인사이트 요약 (50자 이상)**
> 판매지수와 리뷰 수 간의 상관계수는 0.361로 양의 상관관계를 띱니다. 이는 판매지수가 높을수록(책이 많이 팔릴수록) 축적되는 리뷰 수가 자연스럽게 증가한다는 명확한 사실을 보여줍니다. 동시에 리뷰 수가 많은 책일수록 후속 구매자들에게 긍정적인 사회적 증거(Social Proof)로 작용하여 판매를 더욱 촉진하는 선순환 구조를 형성합니다.
