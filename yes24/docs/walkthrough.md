# EDA 분석 작업 완료 보고서 (Walkthrough)

`yes24/data/yes24_books.csv` 도서 데이터셋에 대한 탐색적 데이터 분석(EDA) 계획 수립, 분석 환경 구축, 파이썬 기반 데이터 전처리 및 시각화 코드 실행, 그리고 최종 보고서 작성을 모두 정상적으로 완수하였습니다.

## 수행 완료된 작업 내역

1. **분석 환경 조성**:
   - `uv` 가상환경에 데이터 탐색 및 시각화 라이브러리인 `matplotlib` 및 `seaborn` 패키지를 추가로 설치하였습니다.
2. **분석 스크립트 작성**:
   - [eda_analysis.py](../src/eda_analysis.py) 파일을 구현하여 데이터 로드, 전처리, 통계량 분석, 이미지 시각화를 일괄 자동 처리하도록 구현하였습니다.
   - 한글 깨짐을 방지하기 위해 Mac OS 시스템 폰트인 'AppleGothic'을 연동하였습니다.
3. **데이터 전처리 수행**:
   - 정가, 판매가, 리뷰 수, 판매지수의 문자열 요소를 제거하고 수치형 변수로 변환하였습니다.
   - 발행일 정보에서 '발행연도' 및 '발행월'을 추출하는 파생 변수를 개발하였습니다.
   - 정가 대비 판매가를 활용해 각 도서의 할인율(%)을 산출하였습니다.
4. **시각화 산출물 생성**:
   - 다음 5가지 시각화 이미지를 [images/](../images/) 폴더 내에 생성 및 저장하였습니다.
     - `price_discount_dist.png`: 가격 분포 및 할인율(%) 분포도
     - `publish_trend.png`: 연도별 도서 출판 수 추이
     - `sales_review_corr.png`: 리뷰 수와 판매지수 간의 상관관계 산점도 및 피어슨 상관계수
     - `top_publishers_authors.png`: 등록 도서 기준 상위 10대 출판사 및 저자 막대그래프
     - `title_keyword_freq.png`: 도서 제목 핵심 키워드 출현 빈도 차트
5. **분석 리포트 문서화**:
   - 데이터 기초 분석 및 결측치 현황, 기술통계 분석 결과, 시각화 이미지를 통합한 종합 분석 보고서 [eda_report.md](eda_report.md)를 완성하였습니다.
