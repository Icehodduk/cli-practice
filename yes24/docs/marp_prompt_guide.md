# 고품질 Marp 발표 자료 생성 마스터 프롬프트 가이드

이 문서는 사용자가 향후 다른 데이터 분석 결과나 보고서를 바탕으로 동일한 수준의 고품질 Marp 프레젠테이션 슬라이드를 생성하고자 할 때, 대형 언어 모델(LLM)에 입력할 수 있도록 설계된 **마스터 프롬프트(Master Prompt) 템플릿**입니다.

---

## 1. Marp 슬라이드 생성 마스터 프롬프트

아래의 프롬프트 텍스트를 통째로 복사하여 ChatGPT나 Claude 등 AI에 입력하고, 하단의 `[여기에 분석 결과 및 입력 데이터를 기입]` 부분만 실제 분석 데이터로 채워 넣으시면 됩니다.

```markdown
당신은 최고의 데이터 스토리텔러이자 프레젠테이션 디자이너입니다.
주어진 데이터 분석 결과와 인사이트 리포트를 바탕으로, 발표용 Marp(Markdown Presentation) 슬라이드 코드를 작성해 주세요. 
아래에 제시된 스타일 시스템, 구조적 가이드라인, 그리고 발표자 대본 작성 규칙을 엄격하게 준수해야 합니다.

---

### [RULE 1] Marp 프레임워크 및 커스텀 스타일 설정
1. 문서의 맨 위(Frontmatter)는 반드시 다음 설정을 포함해야 합니다.
   - `marp: true`
   - `theme: gaia`
   - `paginate: false` (페이지 하단 번호 출력 끄기)
   - `_class: lead` (표지 클래스 설정)
2. 스타일 커스텀 블록(`style: |`)을 내장하여 다음 디자인 시스템을 반영하세요.
   - 폰트: `'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif` 일관 적용
   - 기본 글자 색상: `#333333` / 배경색: 연한 크림화이트 `#F8F9FA`
   - 메인 헤더(`h1`): `#1B365D` (짙은 네이비), 폰트 크기 `1.6em`, 아래에 얇은 스틸 블루(`#4682B4`) 테두리선 배치
   - 서브 헤더(`h2`): `#4682B4` (스틸 블루), 폰트 크기 `1.2em`
   - 간지 및 표지(`_class: lead`): 배경색 `#1B365D` (짙은 네이비), 글자색 `#FFFFFF` (흰색), 텍스트 가운데 정렬
   - 인용구(`blockquote`): 배경색 `#F0F4F8`, 좌측 테두리선 `5px solid #1B365D`
   - 테이블(`table`): 폰트 크기 `0.65em`, 헤더는 스틸 블루 배경에 흰색 폰트 적용

### [RULE 2] 제목 서식 규정 (수치 일련번호 제외)
- 각 슬라이드의 제목(`h1`, `h2`) 작성 시, 순서나 번호를 매기는 수치 레이블을 절대 사용하지 마세요.
- **나쁜 예**: `1. 프로젝트 개요`, `[시각화 01] 가격 분포`, `[인사이트 02] 할인 정책`
- **좋은 예**: `프로젝트 개요 및 분석 목표`, `도서 정가 및 판매가 분포`, `법적 테두리 속의 할인율 통일성`

### [RULE 3] 세션별 간지(Break Slide) 및 흐름 구성
- 대주제가 바뀌거나 새로운 단락이 시작될 때는 반드시 흐름을 잡아주는 '간지 슬라이드'를 삽입하세요.
- 간지 슬라이드는 `<!-- _class: lead -->`를 맨 위에 적어 짙은 네이비 배경 테마로 적용하고, 대분류 세션 제목과 부제목을 중앙 정렬하여 시각적 구분을 제공하세요.

### [RULE 4] 시각화 이미지 겹침 방지 및 우측 배치 레이아웃
- 그래프 이미지(차트)가 들어가는 슬라이드는 마크다운 이미지 삽입 시 반드시 Marp 전용 우측 분할 배경 문법인 `![bg right:45% fit](이미지 상대경로)` 형식을 사용하세요.
- 슬라이드의 우측 45% 영역에는 이미지를 맞춤형(fit)으로 채워 넣고, 좌측 55% 영역에는 분석 수치 요약 표(Table) 또는 텍스트 목록을 적어 텍스트와 그래프가 절대 겹치지 않게 하세요.

### [RULE 5] 슬라이드별 2분 분량 발표자 대본(Speaker Notes) 필수 포함
- **가장 중요한 규칙**: 모든 슬라이드 하단에 반드시 `<!-- [발표자 대본 - 2분 분량] ... -->` 주석 블록을 작성하세요.
- 스피커 노트의 분량은 **슬라이드 한 장당 공백 포함 최소 550자 ~ 700자 이상**의 정교하고 세밀한 분량이어야 합니다.
- 단순히 화면에 적힌 텍스트를 읽는 수준을 넘어서야 합니다. 발표자가 청중을 바라보며 "안녕하십니까...", "여기에 보시는 그래프는...", "이 데이터가 현업 비즈니스에 시사하는 요점은..." 과 같이 자연스러운 격식체 구어체로 설명하는 완벽한 실전 대본을 작성하세요.

---
```

## 2. 프롬프트 사용법 및 팁

1. **상대경로 이미지 관리**:
   * 프롬프트를 사용할 때 이미지 경로가 들어가는 부분은 `../images/파일명.png` 와 같이 상대경로 형식으로 생성되도록 데이터 기입 시 미리 경로를 명시해 주면 컴파일 오류를 예방할 수 있습니다.
2. **슬라이드 분량 조절**:
   * "30장 이상"과 같은 요건을 확실히 달성하기 위해서는 분석 리포트의 개별 그래프별로 **[차트 시각화 슬라이드]**와 **[해당 차트의 비즈니스 인사이트 슬라이드]**를 항상 1:1로 짝지어 구성하도록 프롬프트에 요청하면 자연스럽게 장수가 두 배로 늘어납니다.
3. **Marp 컴파일 시 로컬 파일 보안 우회**:
   * HTML 또는 PDF 추출 시 이미지가 엑박이 뜨는 현상을 방지하기 위해 Marp CLI 빌드 시 `--allow-local-files` 옵션을 주거나, VS Code Marp 설정에서 `Marp: Allow Local Files` 설정을 반드시 켜둔 뒤 내보내기를 실행하세요.
